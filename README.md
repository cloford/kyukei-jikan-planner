# 休憩時間算出アプリ

1日の案件を時間軸に入力すると、案件の間に取れる休憩と、その日の休憩案を表示するスマートフォン向けアプリです。ログインは不要です。

## 基本の使い方

1. **「＋ 案件追加」**を押し、時間軸の空白を縦になぞって開始・終了時刻を決めます。時刻は5分刻みです。
2. 作成した案件をタップすると編集できます。案件の帯を動かして時刻を変更したり、上下のつまみで長さを変えたりできます。
3. **「案件一覧」**を開くと、案件名と開始・終了時刻を直接入力できます。案件の削除や、表示する日付の切り替えもここで行います。
4. 間違えたときは**「元に戻す」**を押します。**「リセット」**は確認後、その日だけの案件を消します。リセット直後も元に戻せます。

通常の画面では、時間軸のどこからでもページを縦にスクロールできます。案件の作成や移動は、追加・編集操作に入ったときだけ行われます。時間軸の表示範囲は **06:00〜21:00** です。

## 表示される休憩時間

- **実際の休憩時間**：最初の案件の開始から、最後の案件の終了5分後までを「拘束時間」とし、そこから8時間を引いた時間です。マイナスになる場合は0分と表示します。
- **取れる最大時間**：案件の前後5分を除いた、条件上休憩に使える時間の最大合計です。
- **休憩案**：実際の休憩時間を、案件と案件の間に割り振ったものです。合計は実際の休憩時間と一致します。休憩案は時間軸上に表示されます。

休憩案には、案件の前後5分を空けること、休憩までの間隔を5時間以内にすること、1日3回以内、1回10分以上という条件があります。条件どおりに割り振れない日は **「成立しません」** と表示します。休憩が不要な短い日は0回で成立する場合があります。

## データの保存

案件は日付ごとに、使用中のブラウザ内に保存されます。同じブラウザ・同じ端末で再び開くと続きから使えます。別の端末との同期はありません。ブラウザのサイトデータを消すと、保存した案件も消えます。

## 自分のパソコンで動かす

静的なHTML・CSS・JavaScriptで作られています。Pythonが使える場合は、このリポジトリをダウンロードして、フォルダー内で次を実行してください。

```sh
python -m http.server 8000 --directory dist
```

その後、ブラウザで `http://localhost:8000` を開きます。

## テスト

Node.jsが使える場合は、次のコマンドで休憩計算のテストを実行できます。

```sh
node --test tests/calculation.test.mjs tests/allocated.test.mjs
```
