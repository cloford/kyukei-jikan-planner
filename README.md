# 休憩時間算出アプリ

スマートフォンで1日の案件を入力し、条件に合う休憩案を確認するブラウザアプリです。ログインは不要です。

## 使い方

1. 「＋ 案件追加」を押し、時間軸の空白を縦になぞって開始・終了時刻を決めます。時間軸は06:00〜21:00で、5分刻みに吸着します。
2. 案件をタップすると時間軸で編集できます。帯を動かして時刻をずらし、上下のつまみで長さを変えます。「案件一覧」では名前と時刻の直接入力、削除ができます。
3. 時間軸の上に「拘束時間」と「休憩案」が表示されます。拘束時間は最初の案件開始から最後の案件終了5分後までです。休憩合計は「1時間15分」「0時間45分」のように表示します。条件を満たせない日は、その日の案件と設定から判定した理由も表示されます。
4. 歯車ボタンから「1回あたりの最短時間」を10〜40分の5分刻みで変更できます。初期値は30分です。変更後、休憩案はすぐに再計算されます。別の日の案件も、この設定画面の日付切り替えから開けます。
5. 「リセット」は確認画面なしで、選択中の1日だけを空にします。「元に戻す」で復元できます。ほかの日の案件や最短時間の設定は変わりません。

休憩案に割り当てる合計時間は、拘束時間から8時間を引いた時間（マイナスなら0分）です。各案件の前後5分を空け、最初の案件から最初の休憩までと休憩間を5時間以内、休憩は3回以内とし、選択した1回あたりの最短時間を守ります。最後の休憩から最後の案件終了までの長さは判定しません。

案件は日付ごとに、このブラウザの `localStorage` に保存されます。最短時間の設定は日付をまたいで保存され、案件のリセットでは変わりません。ブラウザのデータを消すと保存内容も消えます。

## Androidで使う

1. F-51B（Android 14）のChromeで、[休憩時間算出アプリ](https://kyukei-8450f089bb4742dba6921a253ceac22e.cloford1121.chatgpt.site/)を開きます。初回の読み込みには通信が必要です。
2. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選び、追加したアイコンから起動します。メニューの表示名はChromeの状態によって異なる場合があります。
3. アプリの「設定」を開き、「オフラインで利用できます」と表示されるまでオンラインのまま待ちます。この表示を確認してから通信を切ります。
4. オフラインで案件を新規作成し、案件を編集します。アプリを閉じて開き直し、作成・編集した内容が残っていることを確認します。初回読み込みや未取得の更新版の取得はオフラインではできません。

アプリはオンライン復帰時と画面再表示時に更新を確認します。設定の「アプリの更新を確認」から手動でも確認できます。更新版の準備ができた後、切り替えるにはPWA画面だけでなく、同じページを開いているChromeタブもすべて閉じてから、アプリを開き直してください。

案件と最短時間の設定はブラウザ内に保存されます。Chromeのサイトデータや閲覧データを消去すると、保存した案件と設定も消えます。ホーム画面のアイコンを削除してもサイトデータは別に残ります。アプリ更新時には案件や設定を消去しません。新版へ切り替わった後、不要な旧版キャッシュだけを削除します。

F-51B実機でのインストール・オフライン動作・更新は未検証です。Androidアプリとしての関連付け（TWA）は未成立です。`/.well-known/assetlinks.json` は調査用に配置していますが、正式なパッケージ名と署名証明書のSHA-256指紋が未作成のため、Androidアプリとの関連付けには使えません。

## 将来のGoogle Play公開について

現在の公開URLを維持し、Manifestの `id`・`start_url`・`scope` は `/` に固定しています。これらはアプリの識別と起動範囲に関わるため、通常の機能更新では変更しません。

2026-10-08に現在の公開先で `/.well-known/assetlinks.json` がリダイレクトなしのHTTP 200・`application/json`で取得できることを確認しました。内容は空の配列 `[]` で、まだAndroidアプリへの権限付与は行っていません。将来TWAを作る際は、正式なAndroidパッケージ名と、Google Play App Signingで配布に使う署名証明書のSHA-256指紋を決め、`delegate_permission/common.handle_all_urls` の関連付けをこのファイルに設定します。Android側にも同じ公開オリジンの関連付けを設定し、検証が通ることを確認する必要があります。

参考：[Chrome公式のTWA導入ガイド](https://developer.chrome.com/docs/android/trusted-web-activity/integration-guide)。今回はAPK作成、Google Play登録・申請は行いません。

## 開発者向け

公開版ごとの変更内容は[バージョン情報](CHANGELOG.md)に記載しています。

`dist/index.html` を静的サイトとして配信します。計算処理は `dist/calculation.js` にあります。

ソースアセットを変更した後は `node scripts/build-pwa.mjs` を実行して配信用ファイルを生成します。アイコンの生成には `node scripts/generate-icons.mjs` を使います。テストは `node --test tests/*.test.mjs`、ローカルでの確認用サーバーは `node scripts/serve.mjs` で起動します。
