# 休憩時間算出アプリ

スマートフォンで1日の案件を入力し、条件に合う休憩案を確認するブラウザアプリです。ログインは不要です。

## 使い方

1. 「＋ 案件追加」を押し、時間軸の空白を縦になぞって開始・終了時刻を決めます。時間軸は06:00〜21:00で、5分刻みに吸着します。
2. 案件をタップすると一覧が開き、名前と時刻を直接変更できます。一覧の「時間軸で編集」から、スワイプによる移動や長さ調整もできます。
3. 時間軸の上に「拘束時間」と「休憩案」が表示されます。拘束時間は最初の案件開始から最後の案件終了5分後までです。休憩案が条件を満たせない日は「成立しません」と表示されます。
4. 歯車ボタンから「1回あたりの最短時間」を10〜40分の5分刻みで変更できます。初期値は30分です。変更後、休憩案はすぐに再計算されます。

休憩案に割り当てる合計時間は、拘束時間から8時間を引いた時間（マイナスなら0分）です。各案件の前後5分を空け、最初の案件から最初の休憩までと休憩間を5時間以内、休憩は3回以内とし、選択した1回あたりの最短時間を守ります。最後の休憩から最後の案件終了までの長さは判定しません。

案件は日付ごとに、このブラウザの `localStorage` に保存されます。最短時間の設定は日付をまたいで保存され、案件のリセットでは変わりません。ブラウザのデータを消すと保存内容も消えます。

## 開発者向け

`dist/index.html` を静的サイトとして配信します。計算処理は `dist/calculation.js` にあります。

テスト: `node --test tests/calculation.test.mjs tests/allocated.test.mjs`
